# 🚀 EduVerse AI Lite

A futuristic, full-stack AI learning web app. Enter any topic and get instant explanations,
quizzes, and personalized study plans — powered by any LLM available on [OpenRouter](https://openrouter.ai).

![Tech](https://img.shields.io/badge/frontend-React%20%2B%20Vite-blue) ![Tech](https://img.shields.io/badge/backend-FastAPI-teal) ![Tech](https://img.shields.io/badge/db-SQLite-lightgrey) ![Tech](https://img.shields.io/badge/AI-OpenRouter-purple)

---

## ✨ Features

| Page | What it does |
|---|---|
| **Home** | Modern glassmorphism landing page — hero, features, about, contact footer |
| **AI Teacher** | Enter a topic → get an easy explanation, 5 key points, 3 examples, 5 quiz questions, and a summary |
| **AI Quiz** | Enter a topic → get a 10-question multiple-choice quiz, submit it, and see your score, percentage, and correct answers |
| **Study Planner** | Enter subjects, hours/day, and exam date → get a clean day-by-day study timetable |

---

## 🧱 Tech Stack

- **Frontend:** React 18 + Vite + Tailwind CSS + React Router
- **Backend:** FastAPI (Python) + Uvicorn
- **Database:** SQLite (stdlib `sqlite3`, zero extra setup — stores history of everything generated)
- **AI:** [OpenRouter API](https://openrouter.ai) (OpenAI-compatible; use any model you like)

## 🔧 Setup & Run

### 1. Clone / unzip the project, then open two terminals.

### 2. Backend (Terminal 1)

```bash
cd backend
python -m venv venv

# Activate the virtual environment
source venv/bin/activate       # macOS/Linux
venv\Scripts\activate          # Windows

pip install -r requirements.txt

# Configure your API key
cp .env.example .env            # macOS/Linux
copy .env.example .env          # Windows
```

Open `backend/.env` and paste your key:

```
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxx
OPENROUTER_MODEL=openai/gpt-4o-mini
```

Then start the API server:

```bash
uvicorn main:app --reload --port 8000
```

The backend will run at **http://localhost:8000**. Visit `http://localhost:8000/api/health`
to confirm it's up — you should see `{"status": "ok", ...}`.

A `eduverse.db` SQLite file is created automatically on first run.

### 3. Frontend (Terminal 2)

```bash
cd frontend
npm install

cp .env.example .env             # macOS/Linux
copy .env.example .env           # Windows
```

The default `VITE_API_BASE_URL=http://localhost:8000` already matches the backend above, so
you usually don't need to change anything.

```bash
npm run dev
```

The app will run at **http://localhost:5173** — open it in your browser.

## 🔑 Getting an OpenRouter API Key

1. Go to https://openrouter.ai and sign up (free).
2. Go to https://openrouter.ai/keys and create a new key.
3. Paste it into `backend/.env` as `OPENROUTER_API_KEY`.
4. Pick any model you like in `OPENROUTER_MODEL` (e.g. `openai/gpt-4o-mini`,
   `anthropic/claude-3.5-haiku`, `google/gemini-flash-1.5`, `meta-llama/llama-3.1-8b-instruct`).
   Some models are free — check https://openrouter.ai/models and filter by price.

## 🔌 API Endpoints (Backend)

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/health` | Health check |
| POST | `/api/teacher` | `{ "topic": "..." }` → explanation, key points, examples, quiz, summary |
| POST | `/api/quiz/generate` | `{ "topic": "...", "num_questions": 10 }` → list of MCQ questions |
| POST | `/api/quiz/submit` | `{ "topic", "questions", "answers" }` → score, percentage, per-question results |
| POST | `/api/planner` | `{ "subjects": [...], "hours_per_day": 3, "exam_date": "YYYY-MM-DD" }` → daily timetable |

Interactive API docs are auto-generated by FastAPI at **http://localhost:8000/docs**.

## 🩹 Troubleshooting

- **"OPENROUTER_API_KEY is not set"** → make sure you copied `.env.example` to `.env` inside
  `backend/` and restarted `uvicorn` after editing it.
- **CORS errors in the browser console** → confirm the backend is running on port 8000 and
  `frontend/.env` points to the correct `VITE_API_BASE_URL`.
- **"AI response was not valid JSON"** → some smaller/free models occasionally misformat
  output. Try a more capable model (e.g. `openai/gpt-4o-mini`) in `backend/.env`.
- **Port already in use** → change `--port 8000` in the uvicorn command and update
  `VITE_API_BASE_URL` in `frontend/.env` to match.
